S2A WARNINGSTAR

DISCORD-BOUND NEWS AGGREGATOR AND THREAT ASSESSMENT SYSTEM

01 SYSTEM OVERVIEW

WARNINGSTAR is a Discord-bound international security data aggregator. It serves as a centralised news feed, providing real-time updates on global events and autonomously categorising them by regions and threat indexes. It takes advantage of the accessibility and security features of Discord as a frontend, while maintaining a robust Python backend.

02 SYSTEM FEATURES

The system is comprised of two core features that operate autonomously via scheduled workflows.

DATA AGGREGATOR ACTIVE
Aggregation & Filtering: Through Github Actions, WARNINGSTAR wakes up every hour to autonomously collect, process, filter, and display events relevant to international security and politics. Each event is tagged with their respective source, country, region of interest, and threat index.

Data Display: Filtered events are posted to their respective regions, through channels representing each US CCMD (Unified Combatant Command). This allows for users to selectively ingest news from their areas of focus, and control the amount of engagement they have accordingly.
THREAT ASSESSMENT ACTIVE
WARNINGSTAR utilises a sophisticated threat assessment algorithm that scores and tags events based on their potential impact on global stability. Ranging from 0 to 10, the algorithm takes into account of the general impact of the event type (elections, armed conflicts, coups, etc.), semantic event type (kinetic, active, passive, speculative) relative effects chain (neighboring states, alliances, enemies), direct impact on regional stability, and historical case parameters.The exact score output is displayed on the event embed itself, and each embed is colour tagged (red, orange, yellow, blue) according to their scores.

03 DEPLOYMENT

While continuously improving, WARNINSTAR is functional and ready for deployment. There is a dashboard server that allows you to use the system in its native environment. You may also invite the system directly into your own server should you wish to do so. Keep in mind that WARNINGSTAR is an entirely autonomous and one-directional system, and it cannot fulfil any real-time user commands nor respond to pings. Both the dashboard server and the invite link are available at the bottom of this page.

Below are the regional feed channels you will need to set up in your server should you wish to invite it. WARNINGSTAR will actively search for, and only post in the exact channels.
