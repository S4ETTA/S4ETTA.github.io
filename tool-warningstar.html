01 // SYSTEM OVERVIEW

WARNINGSTAR is a Discord-bound international security data aggregator. It serves as a news aggregator for discord servers, providing real-time updates on global security issues, and drafting region-based intelligence briefings every week. The system is built on a Python backend integrating specifically with the Discord.py library. It utilises the Discord messaging app as frontend, taking advantage of both its well-designed UI and channel structures, as well as the built-in backend security.

02 // DATA AGGREGATION (Channel Required: #warningstar-feed)

Data Aggregation: WARNINGSTAR autonomously wakes up every 2 hours through Github Actions and collects the newest data from specified and customisable news sources.

Data Filtering: Once collected, the system internally filters through and only maintains articles relevant to the current operational context, through a combination of customisable keyword focuses.

Data Display: Filtered data is displayed in a dedicated Discord channel in the form of an easy-to-read embed summary, and the source url. Each displayed article is saved in an internal database to prevent duplication, and to be used by the AI for weekly briefing.

03 // WEEKLY BRIEFING (Channel Required: #warningstar-brief)

Every Monday at 00:00 UTC, WARNINGSTAR generates a comprehensive weekly intelligence briefing of the past week, summarised and organised by an onboard AI. Each summary is sorted by their respective regions (Americas, US Politics, Europe, MENA, Indopacific)
