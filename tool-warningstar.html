S2A Warningstar

Discord-Bound News Aggregator & Threat Assessment

01 System Overview

WARNINGSTAR is a Discord-bound international security data aggregator. It serves as a centralised news feed, providing real-time updates on global events and autonomously categorising them by regions and threat indexes. It takes advantage of the accessibility and security features of Discord as a frontend, while maintaining a robust Python backend.

02 System Features

The system is comprised of two core features that operate autonomously via scheduled workflows.

Data Aggregator Active
Aggregation & Filtering: Through Github Actions, WARNINGSTAR wakes up every hour to autonomously collect, process, filter, and display events relevant to international security and politics. Each event is tagged with their respective source, country, region of interest, and threat index.

Data Display: Filtered events are posted to their respective regions, through channels representing each US CCMD (Unified Combatant Command). This allows for users to selectively ingest news from their areas of focus, and control the amount of engagement they have accordingly.
Threat Assessment Active
WARNINGSTAR utilises a sophisticated threat assessment algorithm that scores and tags events based on their potential impact on global stability. Ranging from 0 to 10, the algorithm takes into account the general impact of the event type (elections, armed conflicts, coups, etc.), semantic event type (kinetic, active, passive, speculative), relative effects chain (neighbouring states, alliances, enemies), direct impact on regional stability, and historical case parameters. Each embed is colour tagged (red, orange, yellow, blue) according to their scores.

03 Deployment

While continuously improving, WARNINGSTAR is functional and ready for deployment. There is a dashboard server that allows you to use the system in its native environment, currently used by members of Seoul National University. You may also invite the system directly into your own server should you wish to do so. Keep in mind that WARNINGSTAR is an entirely autonomous and one-directional system — it cannot fulfil any real-time user commands nor respond to pings.

The following channels are required in your server for WARNINGSTAR to post correctly:

  • #warningstar-feed
  • #warningstar-northcom
  • #warningstar-southcom
  • #warningstar-centcom
  • #warningstar-eucom
  • #warningstar-indopacom
  • #warningstar-africom
