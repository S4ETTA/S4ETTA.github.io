S2A WARNINGSTAR

DISCORD-BOUND INTERNATIONAL SECURITY DATA AGGREGATOR

01 SYSTEM OVERVIEW

WARNINGSTAR is a Discord-bound international security data aggregator. It serves as a news aggregator for discord servers, providing real-time updates on global security issues, and drafting region-based intelligence briefings every week. The system is built on a Python ba ckend integrating specifically with the Discord.py library. It utilises the Discord messaging app as frontend, taking advantage of both its well-designed UI and channel structures, as well as the built-in backend security.

02 SYSTEM FEATURES

The system is comprised of two core features that operate autonomously via scheduled workflows.

DATA AGGREGATOR ACTIVE
Channel Required: #warningstar-feed

Aggregation & Filtering: Autonomously wakes up every 2 hours and collects the newest data from specified news sources. Internally filters and only maintains articles relevant to the operational context via customisable keyword focuses.

Data Display: Filtered data is displayed in a dedicated Discord channel as an easy-to-read embed summary. Each displayed article is saved to prevent duplication.
WEEKLY BRIEFING ACTIVE
Channel Required: #warningstar-brief

Every Monday at 00:00 UTC, the system generates a comprehensive weekly intelligence briefing of the past week, summarised and organised by an onboard AI. Each summary is sorted by their respective regions (Americas, US Politics, Europe, MENA, Indopacific).
