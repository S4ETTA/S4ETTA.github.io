S7 PHOBOS

GLOBAL EARLY WARNING AND THREAT ASSESSMENT PLATFORM

01 SYSTEM OVERVIEW

PHOBOS is a full-stack threat assessment platform designed to autonomously ingest, normalize, and visualize geopolitical threats in real-time. Unlike traditional news aggregators that simply list headlines, PHOBOS employs a custom graph theory architecture to map relationships between isolated events, identifying "Crisis Clusters" before they hit mainstream saturation.

02 SYSTEM ARCHITECTURE

Phobos is structured into several interconnected pipelines to process disparate data into a unified threat picture.

DATA INGESTION ACTIVE
A multi-vector ingestion pipeline designed for high availability. It features an automated feed handler triggered by GitHub Actions that pulls raw JSON payloads from international news feeds. For every data inegsted, a built-in algorithm that utilises levenshtein distance and semantic cosine calculation to ensure duplicate events are not ingested twice.
DATA PROJECTION ACTIVE
Core intelligence is powered by a 27B Parameter Instruction-Tuned Model via a hybrid parsing engine. Data is visualized via NetworkX as a multi-layer planetary graph (Countries, Contingencies, Events, OSINT nodes). The graph holds 45 days worth of events, with each event forming a funnel-shaped timeline framework that acts as the basis for threat analysis and scenario projection. As events are spooled out, an onboard AI continuously assigns a semantic coordinate to the node in order to accurately organise and group contingencies.

03 THREAT MATRIX

The Threat Matrix calculates the quantitative Weighted Threat Score (WTS) of each contingency. The equation combines the historical accumulation of threat points ($S_{total}$) with a "Recency Multiplier" and an "Intensity Weight":

\[ WTS = S_{total} + (S_{today} \times 2.0) + (S_{avg} \times 8.0) \]
  • \(S_{total}\) (Total Score): The historical accumulation of all threat points (Stability).
  • \(S_{today}\) (Recency Multiplier): Events happening now are weighted double to alert analysts to immediate escalations.
  • \(S_{avg}\) (Intensity Weight): The average severity of events. A country with a few high-severity events (War) will rank higher than a country with many low-severity events (Protests).

This formula ensures that active acceleration is prioritized over historical volume. Countries crossing a specific WTS threshold automatically trigger a "Red Alert" state in the UI.

04 PREDICTIVE MODEL

The S14 GLAIVE Procedural Scenario Development Model utilises a dual-pathing algorithm to read real-time signs and arrive at a predictive conclusion for specific user-defined scenarios. FIrst, the built in semantic coordinates, node cross sections, and contextual variables are utilised to group directly and indirectly related events into contingency clusters, and of the clusters, the nodes with the highest similarties and intent alignment are selected. The selected nodes are weighted based on threat index and recency, and then the algorithm uses a refined Bayesian Network to calculate the likely probability of the specific scenario occuring based on historical occurence probability. This process uses approximately 300 hardcoded parameters (e.g. election leads to regional destabilisation, middle eastern conflict leads to higher gas prices, etc.) and an indefinite number of intuitive AI parameters to course-correct and refine the probability. Of the multiple projected eventualities of the defined scenario, the timeline of the highest probability is pitched, and the most likely timeframe is presented to the user.
