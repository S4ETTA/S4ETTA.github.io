S7 PHOBOS

Global Early Warning and Threat Assessment Platform

SYSTEM OVERVIEW

PHOBOS is a top-down global awareness dashboard designed to autonomously aggregate disparate intelligence streams into a unified operational picture, cross referencing spatial and temporal data to find critical patterns of interest for intelligence analysts.

DATA AGGREGATION AND INGESTION

PHOBOS uses an Action-based data aggregator with customisable sources and priority keywords to automatically scrape official and unofficial sources of information. The data is then ingested by the onboard AI and processed into keyword-based objects, which is then sorted by event priorities, guided by mathmatical, historical, and geospatial algorithms.

The processed data is projected into a node graph, with the priority scores being used to project relative and objective threat levels, and to read the escalation patterns to telegraph potential future developments. When a "contingency" in a region is detected, a separate node is created to automatically track its development over time, connecting all related events and calculating their threat indexes in real-time.

ANALYSIS FEATURES

Each event is stamped onto a geospatial map for visual analysis, and are logged onto a table for necessary corrections. Each region above a certain threat level can be isolated, briefed, and exported as a report for man-in-the-loop analysis. The system also supports manual data input and ingestion when needed for HUMINT or OSINT sources.
