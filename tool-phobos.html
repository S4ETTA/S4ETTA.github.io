S7

GLOBAL EARLY WARNING AND THREAT ASSESSMENT PLATFORM

01 SYSTEM OVERVIEW

PHOBOS is a Dockerized, full-stack intelligence dashboard designed to autonomously ingest, normalize, and visualize geopolitical threats in real-time. Unlike traditional news aggregators that simply list headlines, PHOBOS employs a custom graph theory architecture to map relationships between isolated events, identifying "Crisis Clusters" before they hit mainstream saturation.

02 DATA INGESTION

The system utilizes a multi-vector ingestion pipeline designed for high availability. It features an automated feed handler triggered by GitHub Actions that pulls raw JSON payloads from international news feeds. Simultaneously, it integrates a manual injection protocol, allowing analysts to merge classified HUMINT or offline OSINT notes directly into the stream.

03 DATA PROJECTION

Core intelligence is powered by a 27B Parameter Instruction-Tuned Model (Gemma 3). The extraction process uses a hybrid parsing engine: a primary layer enforces strict JSON schema for event scoring, while a secondary Regex safety net recovers data if the model produces unstructured text. Data is visualized via NetworkX as a multi-layer planetary graph, each layer representing a specific data type. This structure ensures the graph is not just a cluster of nodes, but an observable data source. Layer 1 projects countries, Layer 2 projects contingencies and live data (NOTAM, USGS, FR24, Travel Advisories), Layer 3 projects event nodes, and Layer 4 projects OSINT nodes. Duplicate and reposted events are filtered out using Levenshtein distance and crisis node connections in order to maintain accuracy in threat assessment.

04 THREAT MATRIX

The Threat Matrix moves beyond qualitative description to a quantitative Weighted Threat Score (WTS). The equation combines the historical accumulation of threat points ($S_{total}$) with a "Recency Multiplier" and an "Intensity Weight":

\[ WTS = S_{total} + (S_{today} \times 2.0) + (S_{avg} \times 8.0) \]
  • \(S_{total}\) (Total Score): The historical accumulation of all threat points (Stability).
  • \(S_{today}\) (Recency Multiplier): Events happening now are weighted double to alert analysts to immediate escalations.
  • \(S_{avg}\) (Intensity Weight): The average severity of events. A country with a few high-severity events (War) will rank higher than a country with many low-severity events (Protests).

This formula ensures that active acceleration is prioritized over historical volume. Countries crossing a specific WTS threshold automatically trigger a "Red Alert" state in the UI.

05 TEMPORAL RECURSION MODEL

The Temporal Recursion Model (TRM) utilises a sophisticated prediction algorithm to read and project future scenario escalation. The algorithm uses an onboard database to find historical patterns on a developing scenario and sequentialises the pattern into a "shadow event", which is then matched with the current event to determine the probability of future escalation. The TRM allows the user to observe ongoing events in real-time and react or adjust accordingly. TRM is currently under training and testing.
