S7 PHOBOS

// GLOBAL EARLY WARNING AND THREAT ASSESSMENT PLATFORM

01 // SYSTEM OVERVIEW

PHOBOS is a Dockerized, full-stack intelligence dashboard designed to autonomously ingest, normalize, and visualize geopolitical threats in real-time. Unlike traditional news aggregators that simply list headlines, PHOBOS employs a custom Graph Theory architecture to map relationships between isolated events, identifying "Crisis Clusters" before they hit mainstream saturation. By transforming raw, unstructured noise into a quantifiable Weighted Threat Score (WTS), it serves as a force-multiplier for intelligence analysts, automating the initial triage phase of the intelligence cycle.

02 // DATA AGGREGATION AND INGESTION

The system utilizes a multi-vector ingestion pipeline designed for high availability and zero data loss. It features an automated feed handler triggered by GitHub Actions that pulls raw JSON payloads from international news feeds and deposits them into a localized processing queue. Simultaneously, the system integrates a manual injection protocol (Protocol 5A), allowing analysts to merge classified HUMINT or offline OSINT notes directly into the automated data stream. To prevent API bottlenecks during high-volume news cycles, the ingestion engine utilizes an autonomous Exponential Backoff mechanism that throttles intake speed upon detecting rate limits, ensuring continuous operation without crashing.

03 // DATA EXTRACTION AND PROJECTION

This is the core of the PHOBOS intelligence engine, powered by a 27B Parameter Instruction-Tuned Model (Gemma 3) that moves beyond simple keyword matching to perform semantic understanding. The extraction process uses a hybrid parsing engine: a primary layer enforces strict JSON schema for event scoring and location data, while a secondary Regex safety net recovers data if the model produces unstructured text, ensuring near-perfect ingestion reliability.

To solve the issue of duplicate reporting, PHOBOS employs a Retrieval-Augmented Normalization strategy. Before processing, the system dynamically injects a list of active contingencies into the AI's context, allowing it to semantically map new headlines to existing crisis IDs (e.g., mapping "Khan Yunis" to "Israel-Gaza Conflict"). Finally, data is visualized via NetworkX as a gravity-based graph where events "orbit" central Crisis Nodes, allowing analysts to gauge conflict intensity by cluster density.

04 // THREAT MATRIX

The Threat Matrix moves beyond qualitative description to a quantitative Weighted Threat Score (WTS), calculated to prioritize active acceleration over historical volume. The equation combines the historical accumulation of threat points ($S_{total}$) with a "Recency Multiplier" ($S_{today} \times 2.0$) and an "Intensity Weight" ($S_{avg} \times 8.0$). This formula ensures that a country experiencing a sudden, high-intensity spike (like a war outbreak) ranks higher than a country with a long history of low-level unrest. Countries crossing a specific WTS threshold automatically trigger a "Red Alert" state in the UI, locking the dashboard to that region for immediate assessment.

05 // FUTURE PLANS

The roadmap for PHOBOS involves moving from Description to Prediction through an Event Variance Projection (EVP) engine. Currently in development, this predictive model adapts financial stochastic forecasting to geopolitical volatility. It is designed to draft one to three probabilistic timelines (Best, Worst, and Likely cases) displayed as diverging graph lines over a 48-hour horizon. These projections will be based on historical case data, regional context, and key driver events. Additionally, core components of the graph logic are scheduled to be released as open-source libraries to contribute to the wider OSINT developer community.
