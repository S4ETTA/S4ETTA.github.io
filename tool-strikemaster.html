S9 STRIKEMASTER

GEOSPATIAL ANALYSIS PLATFORM

01 SYSTEM OVERVIEW

STRIKEMASTER is a geospatial intelligence platform specialised in monitoring live military conflicts and assessing kinetic strike effects. Utilising an advanced high resolution satellite imagery fetching system, it is assisted by a number of tools to provide in-depth data analysis and visualisation.

02 BASE PLATFORM

The system is built on a modular architecture, with the baseline STRIKEMASTER serving as a database and data processing platform. The system also provides basic GIS features, and allows for modular upgrades. The analytical core runs on Gemma-3-27b, with support for both data extraction and projection. The primary visual feed utilises multiple satellite imagery sources loading simultanaeously to provide a wide range of image date and faster loading.

STRIKEMASTER features a smart crosshairs system that adapts to the mode being used and displays all necessary information without cluttering the visual feed. N/E and MGRS coordinates, imperial and metric distance markers, and altitude markers are displayed on the crosshairs, and allows for both coordinate injection and export.

03 MODULES

The system includes various modular components for specialized analysis.

STRIKE ACTIVE
An educative tool for automatically assessing regional vulnerabilities and potential targets. Utilises a contextual learning protocol to provide the most updated and accurate information. Offers operation and target type presets to allow for a wide variety of scenarios to be simulated.
CASIO ACTIVE
Combined Aperture Satellite Imagery Overlay: Satellite imagery fetcher with access to Sentinel 1 GRD C-Band, Sentinel 2 L2A True Colour, Sentinel 2 L2A B08 NIR, Sentinel 2 L2A B12 SWIR, Sentinel 2 L2A NDVI, Sentinel 2 L2A NDWI, and Sentinel 3 SLSTR THERMAL. Allows for image data controls, snapshots, and exports.
LASIOR ACTIVE
Low Altitude Satellite Imagery Object Recognition: AI-enhanced object recognition system that utilises both regional contextual data and machine learning to identify objects of interest. Currently being trained for detailed aircraft identification.
CANVAS ACTIVE
Visualisation tool for the creation and exporting of comprehensive geospatial analysis reports, complete with detailed adaptive display elements directly integrated into the HUD.
OKSA PLANNED
Optical Kinetic Strike Assessment: Data visualisation tool for assessing the effects of precision guided munitions and creating a comprehensive data sheet to be exported and shared.
GESET PLANNED
Geographical, Environmental, and Social Element Tracker: Analytical model synthesising multi-aperture satellite imagery and land cover data to evaluate sub-conscious navigational trends. By correlating terrain features with behavioural patterns, it predicts likely movement corridors and shelter preferences to aid in environmental familiarity mapping and search operations.
